## Match Statement

`match` dispatches on a value and executes the first arm whose pattern matches.

**Syntax:**

```quant
match <expr> {
    <pattern> => <statement>;
    ...
};
```

Arms are checked top to bottom. The first match wins; remaining arms are skipped. If no arm matches the statement is a no-op (use a wildcard `_` to guarantee a catch-all).

### Patterns

| Pattern | Syntax | Matches when |
|---------|--------|-------------|
| Integer literal | `42` | subject equals 42 |
| Integer range | `1..9` | subject is between 1 and 9 (inclusive) |
| Wildcard | `_` | always |
| `ok` branch | `ok(v)` | `orerror` value is the success case; binds `v` |
| `err` branch | `err(E v)` | `orerror` value is error `E`; binds `v` |

### Value matching

```quant
fn classify(n: int) -> str {
    match n {
        0     => return "zero";
        1..9  => return "single digit";
        10..99 => return "two digits";
        _     => return "large";
    };
    return "unreachable";
}

fn main() -> void {
    println(classify(0));   // zero
    println(classify(7));   // single digit
    println(classify(42));  // two digits
    println(classify(100)); // large
}
```

### Handling orerror with match

`match` is the idiomatic way to branch on an `orerror(T, E)` result without panicking:

```quant
error ParseError { line: int, msg: str };

fn parse(src: str) -> orerror(int, ParseError) {
    if (src == "") {
        return error ParseError { line: 1, msg: "empty input" };
    };
    return 42;
}

fn main() -> void {
    result: orerror(int, ParseError) = parse("");

    match result {
        ok(n)           => println(`parsed: {n}`);
        err(ParseError e) => println(`error on line {e.line}: {e.msg}`);
    };
    // Output: error on line 1: empty input
}
```

The `err(ErrorName v)` arm binds the full error value to `v`. Fields of `v` are accessible with the usual dot notation (`v.field`).

## Conditional Statements

### If Statement

Execute code conditionally based on a boolean expression.

**Syntax:**

```quant
if (condition) {
    // code executed if condition is true
};
```

**Example:**

```quant
fn main() -> void {
    x: int = 10;

    if (x > 5) {
        println("x is greater than 5");
    };
}
```

### If-Else Statement

Execute one block if condition is true, another if false.

**Syntax:**

```quant
if (condition) {
    // code executed if condition is true
} else {
    // code executed if condition is false
};
```

**Example:**

```quant
fn main() -> void {
    x: int = 3;

    if (x > 5) {
        println("x is greater than 5");
    } else {
        println("x is not greater than 5");
    };
}
```

### Else-If Chain

Chain multiple conditions together.

**Syntax:**

```quant
if (condition1) {
    // executed if condition1 is true
} else if (condition2) {
    // executed if condition1 is false and condition2 is true
} else {
    // executed if all conditions are false
};
```

**Example:**

```quant
fn main() -> void {
    score: int = 85;

    if (score >= 90) {
        println("Grade: A");
    } else if (score >= 80) {
        println("Grade: B");
    } else if (score >= 70) {
        println("Grade: C");
    } else {
        println("Grade: F");
    };
}
```

### Nested If Statements

If statements can be nested inside each other.

```quant
fn main() -> void {
    x: int = 10;
    y: int = 20;

    if (x > 5) {
        if (y > 15) {
            println("Both conditions are true");
        };
    };
}
```

## Loops

### While Loop

Repeat code while a condition is true.

**Syntax:**

```quant
while (condition) {
    // code to repeat
};
```

**Example:**

```quant
fn main() -> void {
    count: int = 0;

    while (count < 5) {
        println(`Count: {count}`);
        count += 1;
    };
}
```

**Output:**

```text
Count: 0
Count: 1
Count: 2
Count: 3
Count: 4
```

<Aside type="caution">
Make sure the loop condition will eventually become false. Forgetting to update the loop variable (e.g., omitting `count += 1`) creates an infinite loop that never terminates.
</Aside>

### For Loop

Loop with initialization, condition, and update in one statement.

**Syntax:**

```quant
for (initialization; condition; update) {
    // code to repeat
};
```

**Example:**

```quant
fn main() -> void {
    for (i: int = 0; i < 5; i += 1) {
        println(`i = {i}`);
    };
}
```

**Output:**

```text
i = 0
i = 1
i = 2
i = 3
i = 4
```

### For Loop Components

The for loop has three parts:

1. **Initialization**: Executed once before the loop starts
2. **Condition**: Checked before each iteration
3. **Update**: Executed after each iteration

```quant
for (i: int = 0; i < 10; i++) {
    //   ^           ^        ^
    //   |           |        |
    //   Init        Cond     Update
};
```

### For Loop with Assignment Operators

```quant
fn main() -> void {
    // Counting up
    for (i: int = 0; i < 5; i += 1) {
        println(i);
    };

    // Counting down
    for (i: int = 5; i > 0; i -= 1) {
        println(i);
    };
}
```

### Nested Loops

Loops can be nested inside each other.

```quant
fn main() -> void {
    for (i: int = 0; i < 3; i++) {
        for (j: int = 0; j < 3; j++) {
            println(`({i}, {j})`);
        };
    };
}
```

**Output:**

```text
(0, 0)
(0, 1)
(0, 2)
(1, 0)
(1, 1)
(1, 2)
(2, 0)
(2, 1)
(2, 2)
```

## Loop Control Statements

### Break Statement

Exit a loop immediately.

```quant
fn main() -> void {
    for (i: int = 0; i < 10; i++) {
        if (i == 5) {
            break;  // Exit loop when i equals 5
        };
        println(i);
    };
    // Output: 0 1 2 3 4 (one per line)
}
```

**With while loop:**

```quant
fn main() -> void {
    count: int = 0;

    while (count < 100) {
        println(count);
        count += 1;

        if (count >= 5) {
            break;  // Exit loop early
        };
    };
    // Output: 0 1 2 3 4 (one per line)
}
```

### Continue Statement

Skip the rest of the current iteration and continue with the next one.

```quant
fn main() -> void {
    for (i: int = 0; i < 10; i++) {
        if (i % 2 == 0) {
            continue;  // Skip even numbers
        };
        println(i);
    };
    // Output: 1 3 5 7 9 (one per line)
}
```

**With while loop:**

```quant
fn main() -> void {
    count: int = 0;

    while (count < 10) {
        count += 1;

        if (count % 2 == 0) {
            continue;  // Skip even numbers
        };
        println(count);
    };
    // Output: 1 3 5 7 9 (one per line)
}
```

## Return Statement

Exit a function and optionally return a value.

**Syntax:**

```quant
return;           // Return from void function
return value;     // Return a value
```

**Example:**

```quant
fn find_first_negative(arr: [int], size: int) -> int {
    for (i: int = 0; i < size; i++) {
        if (arr[i] < 0) {
            return i;  // Return index immediately
        };
    };
    return -1;  // Not found
}

fn main() -> void {
    numbers: [int];
    numbers[0] = 10;
    numbers[1] = 20;
    numbers[2] = -5;
    numbers[3] = 30;

    index: int = find_first_negative(numbers, 4);
    println(`First negative at index: {index}`);  // 2
}
```

## Block Statements

Curly braces `{}` create a new scope. When used as standalone blocks (not attached to a function), they end with `;`.

```quant
fn main() -> void {
    x: int = 10;

    {
        y: int = 20;  // y only exists in this block
        println(`x = {x}, y = {y}`);
    };
    // println(y);  // Error: y not in scope
}
```

## Short-Circuit Evaluation

<Aside type="note">
Logical `&&` and `||` use short-circuit evaluation:

- `a && b` -- if `a` is false, `b` is never evaluated
- `a || b` -- if `a` is true, `b` is never evaluated

This means you can guard potentially unsafe operations behind a condition without worrying about the right-hand side executing.
</Aside>

## Common Patterns

### Loop with Array

```quant
fn main() -> void {
    numbers: [int];
    numbers[0] = 10;
    numbers[1] = 20;
    numbers[2] = 30;
    numbers[3] = 40;
    numbers[4] = 50;

    for (i: int = 0; i < 5; i++) {
        println(`numbers[{i}] = {numbers[i]}`);
    };
}
```

### Finding Maximum

```quant
fn main() -> void {
    numbers: [int];
    numbers[0] = 10;
    numbers[1] = 50;
    numbers[2] = 30;
    numbers[3] = 90;
    numbers[4] = 20;

    max: int = numbers[0];

    for (i: int = 1; i < 5; i++) {
        if (numbers[i] > max) {
            max = numbers[i];
        };
    };
    println(`Maximum: {max}`);  // Maximum: 90
}
```

### Counting Elements

```quant
fn main() -> void {
    numbers: [int];
    numbers[0] = 10;
    numbers[1] = 20;
    numbers[2] = 30;
    numbers[3] = 20;
    numbers[4] = 20;

    target: int = 20;
    count: int = 0;

    for (i: int = 0; i < 5; i++) {
        if (numbers[i] == target) {
            count += 1;
        };
    };
    println(`Count of {target}: {count}`);  // Count of 20: 3
}
```

### Prime Number Check

```quant
import math

fn is_prime(n: int) -> bool {
    if (n < 2) {
        return False;
    };
    if (n == 2) {
        return True;
    };
    if (n % 2 == 0) {
        return False;
    };
    for (i: int = 3; i < int(math.sqrt(float(n))) + 1; i += 2) {
        if (n % i == 0) {
            return False;
        };
    };
    return True;
}

fn main() -> void {
    for (i: int = 1; i <= 20; i++) {
        if (is_prime(i)) {
            println(i);
        };
    };
    // Output: 2 3 5 7 11 13 17 19 (one per line)
}
```

### Nested Loop for 2D Array

```quant
fn main() -> void {
    matrix: [[int]];

    // Initialize
    for (i: int = 0; i < 3; i++) {
        for (j: int = 0; j < 3; j++) {
            matrix[i][j] = i * 3 + j + 1;
        };
    };

    // Print
    for (i: int = 0; i < 3; i++) {
        for (j: int = 0; j < 3; j++) {
            println(matrix[i][j]);
        };
    };
}
```

**Output:**

```text
1
2
3
4
5
6
7
8
9
```
