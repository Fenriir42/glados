## Structs

Structs group related fields under a named type.

### Declaration

```quant
struct Point {
    x: int;
    y: int;
}
```

### Instantiation

```quant
fn main() -> void {
    p: Point = Point { x: 10, y: 20 };
    println(p.x);
    println(p.y);
}
```

### Field Access and Assignment

```quant
fn main() -> void {
    p: Point = Point { x: 0, y: 0 };
    p.x = 5;
    p.y = 15;
    println(`({p.x}, {p.y})`);
}
```

Struct types are named types -- you declare variables with the struct name just like any primitive type.

## Impl Blocks

An `impl` block attaches methods to a struct. A method is a function whose first parameter is named `self` and receives the receiver value.

```quant
struct Vec2 {
    x: float,
    y: float,
}

impl Vec2 {
    fn len_sq(self) -> float {
        return self.x * self.x + self.y * self.y;
    }

    fn scale(self, factor: float) -> Vec2 {
        return Vec2 { x: self.x * factor, y: self.y * factor };
    }

    fn dot(self, other: Vec2) -> float {
        return self.x * other.x + self.y * other.y;
    }
}

fn main() -> void {
    v: Vec2 = Vec2 { x: 3.0, y: 4.0 };
    println(v.len_sq());        // 25.0
    w: Vec2 = v.scale(2.0);
    println(w.x);               // 6.0
    println(v.dot(Vec2 { x: 1.0, y: 0.0 })); // 3.0
}
```

Methods are called with dot syntax: `receiver.method(args)`. The receiver is automatically passed as `self`. Under the hood, each method compiles to a regular function named `TypeName.method` -- there is no virtual dispatch or vtable.

Multiple `impl` blocks for the same type are not yet supported; put all methods in a single block.

## Struct Destructuring

You can unpack multiple struct fields into local variables in a single binding
using `{ field, ... }: Type = expr` syntax, and match against struct shapes in
`match` arms with `{ field, ... }` patterns.

### Let-binding destructuring

```quant
struct Point { x: int, y: int }

fn main() -> void {
    p: Point = Point { x: 3, y: 4 };

    { x, y }: Point = p;
    println(x);   // 3
    println(y);   // 4
}
```

Each listed field name is bound as a local variable with the same name.  The
type annotation (`: Point`) tells the type checker which struct the fields come
from.

### Destructuring in function bodies

```quant
struct Person { name: str, age: int }

fn greet(p: Person) -> str {
    { name, age }: Person = p;
    return `{name} is {age} years old`;
}
```

### Match arm patterns

```quant
fn print_point(p: Point) -> void {
    match p {
        { x, y } => {
            println(x);
            println(y);
        };
    };
}
```

A struct pattern always matches (the type is known statically) and binds all
listed fields as variables scoped to the arm body.
