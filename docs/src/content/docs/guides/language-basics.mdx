## Variables

Variables in Quant must be declared with an explicit type annotation using the colon (`:`) syntax.

### Declaration

```quant
name: type;
```

### Declaration with Initialization

```quant
name: type = value;
```

### Examples

```quant
fn main() -> void {
    // Integer variable
    x: int = 42;

    // Boolean variable
    is_active: bool = True;

    // String variable
    message: str = "Hello";

    // Uninitialized variable
    count: int;
    count = 10;
}
```

## Constants

Use the `const` qualifier to make variables immutable:

```quant
fn main() -> void {
    pi: const float = 3.14159;
    max_size: const int = 100;

    // pi = 3.14;  // Error: cannot modify const variable
}
```

The `const` qualifier can also be used in type declarations:

```quant
matrix: [[const int]];  // Array of arrays containing const integers
```

## Primitive Types

Quant supports several primitive types:

### Integer Types

- **`int`**: Default 32-bit signed integer
- **`int<N>`**: Custom bit-size signed integer (e.g., `int<64>`)
- **`int<N, s>`**: Custom bit-size with signedness (e.g., `int<32, u>` for unsigned)

```quant
a: int = 42;              // 32-bit signed
b: int<64> = 1000000;     // 64-bit signed
c: int<32, u> = 100;      // 32-bit unsigned
```

### Float Types

- **`float`**: Default 64-bit floating-point
- **`float<32>`**: 32-bit floating-point
- **`float<64>`**: 64-bit floating-point

```quant
x: float = 3.14159;
y: float<32> = 2.718;
```

### Boolean Type

- **`bool`**: True or False

```quant
flag: bool = True;
is_valid: bool = False;
```

### String Type

- **`str`**: String type for text

```quant
message: str = "Hello, Quant!";
```

String literals use double quotes. To embed expressions inside a string, use a **backtick string**:

```quant
fn main() -> void {
    name: str = "Quant";
    version: int = 1;
    println(`language: {name}, version: {version}`);
    // language: Quant, version: 1
}
```

Anything inside `{...}` is evaluated as an expression and converted to a string automatically.

<Aside type="tip">
Backtick strings desugar to `string.concat` and `string.to_str` calls internally, so they produce a plain `str` value and can be used anywhere a `str` is expected. See the [Types reference](/reference/types/#string-interpolation) for full details.
</Aside>

### Void Type

- **`void`**: Used for functions that don't return a value

```quant
fn greet() -> void {
    println("No return value");
}
```

## Type Casting

Quant supports explicit type casting using the type name as a function:

```quant
import math

fn main() -> void {
    x: float = 3.14;
    y: int = int(x);  // Cast float to int: y = 3

    z: float = float(42);  // Cast int to float: z = 42.0

    // Casting in expressions
    result: int = int(math.sqrt(16.0));
    println(result);
}
```

## Structs

Structs group related fields under a named type.

### Declaration

```quant
struct Point {
    x: int;
    y: int;
}
```

### Instantiation

```quant
fn main() -> void {
    p: Point = Point { x: 10, y: 20 };
    println(p.x);
    println(p.y);
}
```

### Field Access and Assignment

```quant
fn main() -> void {
    p: Point = Point { x: 0, y: 0 };
    p.x = 5;
    p.y = 15;
    println(`({p.x}, {p.y})`);
}
```

Struct types are named types -- you declare variables with the struct name just like any primitive type.

## Visibility

By default, functions declared with `fn` are visible to any file that imports the module. The `static` keyword restricts a function to the file it is defined in.

```quant
// helpers.qa
fn public_helper() -> void {
    println("visible to importers");
}

static fn internal_helper() -> void {
    println("only visible inside helpers.qa");
}
```

When another file imports `helpers`, it can call `public_helper` but not `internal_helper`. This is Quant's module-level encapsulation mechanism.

## Expressions

### Arithmetic Expressions

```quant
a: int = 10 + 5;      // Addition
b: int = 20 - 8;      // Subtraction
c: int = 6 * 7;       // Multiplication
d: int = 20 / 4;      // Division
e: int = 17 % 5;      // Modulo
```

### Comparison Expressions

```quant
x: bool = (5 > 3);    // Greater than
y: bool = (5 < 3);    // Less than
z: bool = (5 == 5);   // Equal to
w: bool = (5 != 3);   // Not equal to
a: bool = (5 >= 5);   // Greater than or equal
b: bool = (5 <= 3);   // Less than or equal
```

### Logical Expressions

```quant
x: bool = True && False;   // Logical AND
y: bool = True || False;   // Logical OR
z: bool = !True;           // Logical NOT
```

### Bitwise Expressions

```quant
a: int = 5 & 3;       // Bitwise AND
b: int = 5 | 3;       // Bitwise OR
c: int = 5 ^ 3;       // Bitwise XOR
d: int = 5 << 1;      // Left shift
e: int = 5 >> 1;      // Right shift
f: int = ~5;          // Bitwise NOT
```

## Assignment Operators

Any bitwise, arithmetic, or logical expression can be assigned to a variable using the assignment operator (`=`). Compound assignment operators are also supported:

```quant
x: int = 10;

x = 20;        // Assignment
x += 5;        // Add and assign: x = x + 5
x -= 3;        // Subtract and assign: x = x - 3
x *= 2;        // Multiply and assign: x = x * 2
x /= 4;        // Divide and assign: x = x / 4
x %= 3;        // Modulo and assign: x = x % 3
```

## Function Calls

Call functions using parentheses:

```quant
fn add(a: int, b: int) -> int {
    return a + b;
}

fn main() -> void {
    result: int = add(5, 3);
    println(`Result: {result}`);
}
```

## Variadic Functions

A parameter declared with `...T` accepts zero or more extra arguments of type `T`. Inside the function the parameter is a `[T]` array -access elements with `[i]` and `len()`.

```quant
fn sum(args: ...int) -> int {
    total: int = 0;
    i: int = 0;
    while (i < len(args)) {
        total = total + args[i];
        i = i + 1;
    };
    return total;
}

fn join(sep: str, parts: ...str) -> str {
    result: str = "";
    i: int = 0;
    while (i < len(parts)) {
        if (i > 0) { result = string.concat(result, sep); };
        result = string.concat(result, parts[i]);
        i = i + 1;
    };
    return result;
}

fn main() -> void {
    println(`{sum(1, 2, 3, 4)}`);            // 10
    println(join(", ", "a", "b", "c"));       // a, b, c
}
```

<Aside>
  The variadic parameter must be the last one. The caller passes arguments directly -no array literal needed at the call site.
</Aside>

The standard library module `varargs` provides ready-made variadic utilities:

| Function | Signature | Description |
|----------|-----------|-------------|
| `sum` | `(args: ...int) -> int` | Sum of all arguments |
| `product` | `(args: ...int) -> int` | Product of all arguments |
| `min` | `(args: ...int) -> int` | Minimum value |
| `max` | `(args: ...int) -> int` | Maximum value |
| `join` | `(sep: str, parts: ...str) -> str` | Join strings with separator |
| `format` | `(template: str, args: ...str) -> str` | Replace `{}` holes in order |

```quant
from varargs import sum, join, format

fn main() -> void {
    println(`{sum(10, 20, 30)}`);
    println(join(" | ", "one", "two", "three"));
    println(format("hello {} and {}", "alice", "bob"));
}
```

```text
60
one | two | three
hello alice and bob
```

## First-Class Functions

Functions are values. You can store them in variables, pass them as arguments,
and create anonymous functions inline with `fn`.

### Function type syntax

A function type is written as `(param-types) -> return-type`:

```quant
f: (int) -> int          // a function taking int, returning int
g: (int, str) -> bool    // two params
h: () -> void            // no params, no return
```

Parameter names are optional: `(int) -> int` and `(x: int) -> int` are
interchangeable as types.

### Function references

Write a named function's identifier (without `()`) to get a reference to it:

```quant
from math import abs

negate: (int) -> int = abs;
println(negate(-42));    // 42
```

### Lambda expressions

Use `fn` as an expression to define an anonymous function inline:

```quant
square: (int) -> int = fn(x: int) -> int { return x * x; };
println(square(6));    // 36
```

### Higher-order functions

Accept or return functions through typed parameters:

```quant
fn apply(f: (int) -> int, x: int) -> int {
    return f(x);
}

fn double(n: int) -> int { return n * 2; }

fn main() -> void {
    println(apply(double, 5));                              // 10 (named ref)
    println(apply(fn(n: int) -> int { return n + 1; }, 5)); // 6 (lambda)
}
```

### Closures

A lambda automatically captures variables from its enclosing scope **by value** at the point it is created. The captured copy is independent of the original, later mutations to the outer variable do not affect the closure.

```quant
fn make_adder(n: int) -> (int) -> int {
    return fn(x: int) -> int { return x + n; };  // n is captured
}

fn main() -> void {
    add5: (int) -> int = make_adder(5);
    add10: (int) -> int = make_adder(10);
    println(add5(3));    // 8
    println(add10(3));   // 13

    // Value-capture: mutating the original does not affect the closure
    base: int = 42;
    get: () -> int = fn() -> int { return base; };
    base = 999;
    println(get());      // 42
}
```

Multiple variables can be captured, and closures can be composed:

```quant
fn compose(f: (int) -> int, g: (int) -> int) -> (int) -> int {
    return fn(x: int) -> int { return g(f(x)); };
}

fn main() -> void {
    add2: (int) -> int = make_adder(2);
    times10: (int) -> int = fn(x: int) -> int { return x * 10; };
    f: (int) -> int = compose(add2, times10);
    println(f(5));   // (5+2)*10 = 70
}
```

## Tuples

A tuple groups a fixed number of values of different types into one compound value. Unlike structs, tuples have no field names - elements are accessed by their zero-based index.

### Type syntax

Write a tuple type as a comma-separated list of types inside parentheses:

```quant
point: (int, int) = (3, 4);
pair:  (int, str) = (42, "hello");
triple: (int, int, int) = (1, 2, 3);
```

A tuple type must have at least two elements. Single-element parentheses are parsed as a grouping expression, not a tuple.

### Indexed access

Use `.0`, `.1`, `.2`, ... to read elements:

```quant
fn main() -> void {
    p: (int, int) = (10, 20);
    println(p.0);   // 10
    println(p.1);   // 20
}
```

### Returning multiple values

Tuples are the idiomatic way to return more than one value from a function without defining a struct:

```quant
fn min_max(a: int, b: int) -> (int, int) {
    if (a < b) {
        return (a, b);
    };
    return (b, a);
}

fn main() -> void {
    result: (int, int) = min_max(7, 3);
    println(result.0);   // 3
    println(result.1);   // 7
}
```

### Destructuring in let

Bind each element directly to a named variable:

```quant
fn main() -> void {
    (lo, hi): (int, int) = min_max(7, 3);
    println(lo);   // 3
    println(hi);   // 7
}
```

The type annotation after `:` must be a tuple type that matches the right-hand side.

### Destructuring in match

Tuple patterns work in `match` arms:

```quant
fn describe(t: (int, int)) -> str {
    match t {
        (0, 0) => { return "origin"; };
        (x, 0) => { return "on x-axis"; };
        (0, y) => { return "on y-axis"; };
        (a, b) => { return "general point"; };
    };
}
```

Each arm binds the elements to fresh local variables in its body.

### Passing tuples to functions

A tuple type is just a type - pass it like any other:

```quant
fn swap(t: (int, int)) -> (int, int) {
    return (t.1, t.0);
}

fn main() -> void {
    s: (int, int) = swap((3, 4));
    println(s.0);   // 4
    println(s.1);   // 3
}
```

## Generic Structs

A struct can be parameterised over one or more type variables using square-bracket syntax after the name. The compiler infers the concrete type arguments from the values you provide at initialisation; the resulting type carries full type information for field access and return types.

### Declaration

```quant
struct Pair[A, B] {
    first: A,
    second: B,
}

struct Box[T] {
    value: T,
    tag: str,
}
```

Type parameters must be used in at least one field. They follow the same rules as function type parameters — a single uppercase letter by convention, but any identifier works.

### Instantiation

Provide the concrete type arguments in the variable declaration; the right-hand side fills the fields as usual:

```quant
fn main() -> void {
    p: Pair[int, str] = Pair { first: 42, second: "hello" };
    println(p.first);    // 42
    println(p.second);   // hello

    b: Box[int] = Box { value: 99, tag: "count" };
    println(b.value);    // 99
    println(b.tag);      // count
}
```

### Generic functions over generic structs

Functions can take generic struct instances as parameters by mirroring the struct's type parameters:

```quant
fn get_first[A, B](p: Pair[A, B]) -> A {
    return p.first;
}

fn get_second[A, B](p: Pair[A, B]) -> B {
    return p.second;
}

fn swap[A, B](p: Pair[A, B]) -> Pair[B, A] {
    return Pair { first: p.second, second: p.first };
}

fn main() -> void {
    p: Pair[int, str] = Pair { first: 7, second: "hello" };
    println(get_first(p));    // 7
    println(get_second(p));   // hello

    s: Pair[str, int] = swap(p);
    println(s.first);         // hello
    println(s.second);        // 7
}
```

The type checker resolves field types through the type-argument binding at each call site; no runtime overhead is added (the implementation is type-erased, like generic functions).

### Returning generic structs

A constructor helper is the idiomatic pattern:

```quant
fn make_pair[A, B](a: A, b: B) -> Pair[A, B] {
    return Pair { first: a, second: b };
}

fn main() -> void {
    q: Pair[int, int] = make_pair(10, 20);
    println(q.first);    // 10
    println(q.second);   // 20
}
```

## Generics

Quant supports parametric polymorphism through type parameters declared in square brackets after the function name. A generic function works with any concrete type supplied at the call site; the type checker verifies correctness for each use.

### Declaring a generic function

```quant
fn identity[T](x: T) -> T {
    return x;
}
```

`T` is a *type parameter* - a placeholder filled in by the caller. The same function can be called with any type:

```quant
fn main() -> void {
    n: int = identity(42);
    s: str = identity("hello");
    println(n);   // 42
    println(s);   // hello
}
```

### Multiple type parameters

List additional type parameters separated by commas:

```quant
fn first[T, U](a: T, b: U) -> T {
    return a;
}

fn main() -> void {
    x: int = first(7, "ignored");
    println(x);   // 7
}
```

### Generics with first-class functions

Type parameters interact naturally with function types, enabling generic higher-order functions:

```quant
fn map_arr[T, U](arr: [T], f: (T) -> U, n: int) -> [U] {
    result: [U] = [];
    i: int = 0;
    while (i < n) {
        push(result, f(arr[i]));
        i++;
    };
    return result;
}

fn main() -> void {
    nums: [int] = [1, 2, 3];
    doubled: [int] = map_arr(nums, fn(x: int) -> int { return x * 2; }, 3);
    println(doubled[0]);   // 2
    println(doubled[2]);   // 6
}
```

<Aside>
  Quant generics use *type erasure*: the same compiled bytecode handles all concrete types. The type checker enforces type safety at each call site with no runtime overhead and no code duplication.
</Aside>

## Scope

Variables are scoped to the block in which they are declared:

```quant
fn main() -> void {
    x: int = 10;  // Outer scope

    {
        y: int = 20;  // Inner scope
        println(x);   // Can access outer scope
    };

    // println(y);  // Error: y not in scope
}
```

## Low-Level I/O

For output beyond `print`/`println`, Quant exposes raw POSIX file descriptors through the `sys` module and a mutable string-buffer type through `buf`.

### Writing to stderr

Use `sys.write` with the standard file descriptor numbers directly:

```quant
import sys

fn main() -> void {
    sys.write(sys.stderr_fd(), "fatal: something went wrong\n");
    sys.exit(1);
}
```

Standard descriptors: `sys.stdin_fd()` = 0, `sys.stdout_fd()` = 1, `sys.stderr_fd()` = 2.

### Opening and reading arbitrary files

```quant
import sys

fn main() -> void {
    fd: int = sys.open("/etc/hostname", sys.o_rdonly());
    if (fd >= 0) {
        content: str = sys.read(fd, 256);
        sys.close(fd);
        println(content);
    };
}
```

Build `flags` for `sys.open` by combining constants with the `|` operator:

| Constant | Meaning |
|----------|---------|
| `sys.o_rdonly()` | Open for reading |
| `sys.o_wronly()` | Open for writing |
| `sys.o_rdwr()` | Open for reading and writing |
| `sys.o_creat()` | Create if absent (mode 0644) |
| `sys.o_trunc()` | Truncate to zero on open |
| `sys.o_append()` | Writes always go to end of file |

### Buffers

`buf.*` provides a mutable accumulation buffer backed by a `[str]` array. Chunks are appended cheaply and joined only when you flush:

```quant
fn eprint(msg: str) -> void {
    b: [str] = buf.new();
    buf.writeln(b, msg);
    buf.flush(b, sys.stderr_fd());
}
```

The `buf.flush(b, fd)` call joins all chunks, writes them to `fd` with a single `write(2)` call, clears the buffer, and returns the byte count. No import statement is needed -`buf.*` functions are always available as dotted calls.

### Building a custom printf

Combining `buf`, `sys`, and `string.replace_first`:

```quant
from sys import write, stdout_fd, stderr_fd
from string import replace_first, from_int, from_float

fn printf(fd: int, fmt: str, args: ...str) -> int {
    b: [str] = buf.new();
    result: str = fmt;
    i: int = 0;
    while (i < len(args)) {
        result = replace_first(result, "{}", args[i]);
        i = i + 1;
    };
    buf.write(b, result);
    return buf.flush(b, fd);
}

fn main() -> void {
    printf(stdout_fd(), "x = {}, pi = {}\n",
           from_int(42), from_float(3.14));
    printf(stderr_fd(), "error: {}\n", "something failed");
}
```

<Aside>
  Mixing `println` (buffered stdout) with `sys.write` or `buf.flush` targeting fd 1 may interleave output unexpectedly. Call `sys.flush(sys.stdout_fd())` first if you need a defined ordering.
</Aside>

## Error Handling

Quant uses `orerror(T, E)` -a built-in result type -instead of exceptions. A function either returns a value of type `T` or a named error `E`.

### Declaring Errors

```quant
error DivisionError;
error ParseError;
```

### Writing Fallible Functions

```quant
fn safe_div(a: int, b: int) -> orerror(int, DivisionError) {
    if (b == 0) {
        return error DivisionError;
    };
    return a / b;
}
```

### Handling the Result

<Tabs>
  <TabItem label="must">
    Unwrap the success value, **panic** at runtime on error:

    ```quant
    x: int = must safe_div(10, 2);   // x = 5
    ```

    Use when you know the call will succeed, or want a hard crash on failure.
  </TabItem>
  <TabItem label="try">
    Unwrap the success value, **propagate** the error if the call fails:

    ```quant
    fn calc(a: int, b: int, c: int) -> orerror(int, DivisionError) {
        x: int = try safe_div(a, b);
        return try safe_div(x, c);
    }
    ```

    The surrounding function must also return `orerror`. If `safe_div` fails, `try` immediately exits the current function with that error.
  </TabItem>
</Tabs>

<Aside type="tip">
  See the [Types reference](/reference/types/#error-types) for the full `orerror` specification including payload fields.
</Aside>
