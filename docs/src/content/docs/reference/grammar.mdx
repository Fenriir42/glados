---
title: Formal Grammar (BNF)
description: Complete BNF grammar of the Quant language
---

This page gives a complete formal grammar for Quant using a Backus–Naur Form (BNF) notation.
Terminals are written in `"double quotes"` or described by a rule name in **bold**.
`*` = zero or more, `+` = one or more, `?` = optional, `|` = alternative, `(…)` = grouping.

---

## Top-level structure

```bnf
<program>   ::= <decl>*

<decl>      ::= <import-decl>
              | <visibility> "fn" <func-decl>
              | <visibility> "struct" <struct-decl>

<visibility> ::= "static" | ε
             -- default (no keyword) = public; "static" = module-private

<import-decl> ::= "import" <module-name>
               |  "from" <module-name> "import" <import-list>

<import-list> ::= <identifier> ("," <identifier>)*
```

---

## Function declarations

```bnf
<func-decl>  ::= <identifier> "(" <param-list>? ")" "->" <type> <block>

<param-list> ::= <param> ("," <param>)*

<param>      ::= <identifier> ":" <qualified-type>
```

---

## Struct declarations

```bnf
<struct-decl> ::= <identifier> "{" <field-list>? "}"

<field-list>  ::= <field> ("," <field>)*

<field>       ::= <identifier> ":" <qualified-type>
```

---

## Error declarations

```bnf
<error-decl>       ::= "error" <identifier> ";"
                      | "error" <identifier> "{" <error-field-list>? "}" ";"

<error-field-list> ::= <error-field> ("," <error-field>)*

<error-field>      ::= <identifier> ":" <type>
```

---

## Types

```bnf
<type>           ::= <primitive-type>
                   | "[" <qualified-type> "]"        -- array type
                   | <identifier>                     -- named / struct type
                   | "orerror" "(" <type> "," <identifier> ")"  -- result type

<qualified-type> ::= "const"? <type>

<primitive-type> ::= "int" | "int" "<" <int-size> ("," <signedness>)? ">"
                   | "float" | "float" "<" <float-size> ">"
                   | "bool"
                   | "str"
                   | "void"
```

---

## Statements

```bnf
<block>  ::= "{" <stmt>* "}"

<stmt>   ::= <var-decl> ";"
           | <assign-stmt> ";"
           | <expr-stmt> ";"
           | <if-stmt> ";"
           | <while-stmt> ";"
           | <for-stmt> ";"
           | <return-stmt> ";"
           | "break" ";"
           | "continue" ";"
           | <block>

<var-decl>    ::= <identifier> ":" <qualified-type> ("=" <expr>)?

<assign-stmt> ::= <lvalue> <assign-op> <expr>

<lvalue>      ::= <identifier>
               | <lvalue> "[" <expr> "]"
               | <lvalue> "." <identifier>

<assign-op>   ::= "=" | "+=" | "-=" | "*=" | "/=" | "%="
                | "&=" | "|=" | "^=" | "<<=" | ">>="
                | "~="

<expr-stmt>   ::= <expr>

<if-stmt>     ::= "if" "(" <expr> ")" <block>
                  ("else" "if" "(" <expr> ")" <block>)*
                  ("else" <block>)?

<while-stmt>  ::= "while" "(" <expr> ")" <block>

<for-stmt>    ::= "for" "(" <for-init>? ";" <expr>? ";" <for-post>? ")" <block>

<for-init>    ::= <var-decl>
               |  <assign-stmt>

<for-post>    ::= <assign-stmt>
               |  <expr>

<return-stmt> ::= "return" <expr>?
```

---

## Expressions

Expressions are listed from **lowest** to **highest** precedence.

```bnf
<expr>        ::= <binary-expr>

<binary-expr> ::= <unary-expr> (<binary-op> <unary-expr>)*

<unary-expr>  ::= <unary-op> <unary-expr>
               |  "must" <unary-expr>              -- unwrap or panic
               |  "try"  <unary-expr>              -- unwrap or propagate
               |  "error" <identifier> ("{" <error-field-init-list>? "}")?  -- create error value
               |  <primary>

<error-field-init-list> ::= <identifier> ":" <expr> ("," <identifier> ":" <expr>)*

<primary>     ::= <literal>
               | <identifier> "{" <field-init-list>? "}"            -- struct init
               | <identifier> "." <identifier> "(" <arg-list>? ")"  -- dotted call
               | <identifier> "(" <arg-list>? ")"                   -- function call
               | <primitive-type> "(" <expr> ")"                    -- type cast
               | <primary> "[" <expr> "]"                           -- index
               | <primary> "." <identifier>                         -- field access
               | <identifier>                                        -- variable
               | "(" <expr> ")"                                      -- parenthesised

<field-init-list> ::= <identifier> ":" <expr> ("," <identifier> ":" <expr>)*

<arg-list>    ::= <expr> ("," <expr>)*
```

### Binary operators (precedence, lowest first)

| Level | Operators | Associativity |
|-------|-----------|---------------|
| 1 | `\|\|` | left |
| 2 | `&&` | left |
| 3 | `==` `!=` | left |
| 4 | `<` `<=` `>` `>=` | left |
| 5 | `\|` | left |
| 6 | `^` | left |
| 7 | `&` | left |
| 8 | `<<` `>>` | left |
| 9 | `+` `-` | left |
| 10 | `*` `/` `%` | left |

```bnf
<binary-op> ::= "||" | "&&"
              | "==" | "!="
              | "<"  | "<=" | ">" | ">="
              | "|"  | "^"  | "&"
              | "<<" | ">>"
              | "+"  | "-"
              | "*"  | "/"  | "%"

<unary-op>  ::= "!" | "-" | "~" | "+"
```

## Literals

```bnf
<literal>    ::= <int-literal>
              |  <float-literal>
              |  <bool-literal>
              |  <string-literal>
              |  <interp-literal>
              |  <array-literal>

<int-literal>    ::= <decimal>
                   | "0x" <hex-digit>+
                   | "0o" <octal-digit>+
                   | "0b" <binary-digit>+

<float-literal>  ::= <decimal> "." <decimal>

<bool-literal>   ::= "True" | "False"

<string-literal> ::= '"' <char>* '"'
                   -- supports escape sequences: \n \t \r \\ \"

<interp-literal> ::= '`' <interp-part>* '`'
                   -- backtick string; {expr} holes are interpolated at runtime

<interp-part>    ::= <any-char-except-backtick-or-brace>+
                   | "{" <expr> "}"

<array-literal>  ::= "[" (<expr> ("," <expr>)*)? "]"

<decimal>        ::= <digit>+
<digit>          ::= "0" … "9"
<hex-digit>      ::= "0" … "9" | "a" … "f" | "A" … "F"
<octal-digit>    ::= "0" … "7"
<binary-digit>   ::= "0" | "1"
```

---

## Lexical elements

```bnf
<identifier>   ::= <letter> (<letter> | <digit> | "_")*

<module-name>  ::= <identifier> ("." <identifier>)*

<letter>       ::= "a" … "z" | "A" … "Z" | "_"

<comment>      ::= "//" <any-char-except-newline>* <newline>
                 | "/*" <any-char>* "*/"
```

### Keywords

```
bool  break  const  continue  else  error  float  fn  for
from  if  import  int  must  orerror  return  str
try  void  while

Contextual keyword (parsed as identifier, not reserved):
static  struct  errorset
```

---

## Operator precedence summary

The grammar implements C-style precedence.  Unary operators bind tighter than
any binary operator, and parentheses override all precedence rules.

```
Highest  unary: !, -, ~, +
         binary: *, /, %
                 +, -
                 <<, >>
                 &
                 ^
                 |
                 <, <=, >, >=
                 ==, !=
                 &&
Lowest   ||
```
