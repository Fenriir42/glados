The Quant standard library is split into nine modules. Built-in functions are accessed via dotted module prefixes (`math.sqrt`, `string.len`, etc.) or via named imports.

## math

Mathematical operations on numeric values.

| Function | Signature | Description |
|----------|-----------|-------------|
| `math.sqrt` | `(int\|float) -> float` | Square root |
| `math.abs` | `(int) -> int` | Integer absolute value |
| `math.fabs` | `(float) -> float` | Float absolute value |
| `math.floor` | `(float) -> int` | Round down to nearest integer |
| `math.ceil` | `(float) -> int` | Round up to nearest integer |
| `math.round` | `(float) -> int` | Round to nearest integer |
| `math.pow` | `(float, float) -> float` | Exponentiation (`b ** e`) |
| `math.exp` | `(float) -> float` | Natural exponential (`e^x`) |
| `math.log` | `(float) -> float` | Natural logarithm |
| `math.sin` | `(float) -> float` | Sine (radians) |
| `math.cos` | `(float) -> float` | Cosine (radians) |
| `math.tan` | `(float) -> float` | Tangent (radians) |
| `math.asin` | `(float) -> float` | Arc sine |
| `math.acos` | `(float) -> float` | Arc cosine |
| `math.atan` | `(float) -> float` | Arc tangent |
| `math.atan2` | `(float, float) -> float` | Two-argument arc tangent (`y, x`) |
| `math.min` | `(int, int) -> int` | Minimum of two integers |
| `math.max` | `(int, int) -> int` | Maximum of two integers |
| `math.fmin` | `(float, float) -> float` | Minimum of two floats |
| `math.fmax` | `(float, float) -> float` | Maximum of two floats |

## string

String inspection and manipulation. All functions operate on `str` values.

| Function | Signature | Description |
|----------|-----------|-------------|
| `string.len` | `(str) -> int` | Number of characters |
| `string.concat` | `(str, str) -> str` | Concatenate two strings |
| `string.substring` | `(str, int, int) -> str` | Substring from `start` (inclusive) to `end` (exclusive) |
| `string.char_at` | `(str, int) -> str` | Single-character string at index |
| `string.contains` | `(str, str) -> bool` | True if second string is a substring |
| `string.starts_with` | `(str, str) -> bool` | True if string starts with prefix |
| `string.ends_with` | `(str, str) -> bool` | True if string ends with suffix |
| `string.index_of` | `(str, str) -> int` | First occurrence index, or -1 |
| `string.last_index_of` | `(str, str) -> int` | Last occurrence index, or -1 |
| `string.to_upper` | `(str) -> str` | Convert to upper case |
| `string.to_lower` | `(str) -> str` | Convert to lower case |
| `string.trim` | `(str) -> str` | Remove leading and trailing whitespace |
| `string.trim_left` | `(str) -> str` | Remove leading whitespace |
| `string.trim_right` | `(str) -> str` | Remove trailing whitespace |
| `string.reverse` | `(str) -> str` | Reverse the string |
| `string.replace` | `(str, str, str) -> str` | Replace all occurrences |
| `string.replace_first` | `(str, str, str) -> str` | Replace first occurrence only |
| `string.repeat` | `(str, int) -> str` | Repeat string `n` times |
| `string.is_empty` | `(str) -> bool` | True if string has length 0 |
| `string.from_int` | `(int) -> str` | Integer to string |
| `string.from_float` | `(float) -> str` | Float to string |
| `string.to_int` | `(str) -> int` | Parse integer (0 on failure) |
| `string.to_float` | `(str) -> float` | Parse float (0.0 on failure) |
| `string.to_str` | `(any) -> str` | Convert any value to its string representation |

`string.to_str` is used internally by backtick string interpolation to convert each `{expr}` to `str`. You can call it directly when you need a manual conversion.

## array

Array operations. The built-in array functions operate on `[int]` arrays at the runtime level; the `std/array.qa` wrappers provide typed aliases.

| Function | Signature | Description |
|----------|-----------|-------------|
| `array.len` | `([int]) -> int` | Number of elements |
| `array.push` | `([int], int) -> void` | Append element (mutates in place) |
| `array.pop` | `([int]) -> int` | Remove and return last element |
| `array.sort` | `([int]) -> void` | Sort array in place (ascending) |
| `array.sum` | `([int]) -> int` | Sum of all elements |

<Tabs>
  <TabItem label="Module prefix">
    ```quant
    import array

    fn main() -> void {
        nums: [int];
        array.push(nums, 10);
        array.push(nums, 20);
        array.push(nums, 30);
        println(array.len(nums));   // 3
        x: int = array.pop(nums);
        println(x);                  // 30
        println(array.sum(nums));    // 30
    }
    ```
  </TabItem>
  <TabItem label="Named import">
    ```quant
    from array import push, pop, len, sort, sum

    fn main() -> void {
        nums: [int];
        push(nums, 30);
        push(nums, 10);
        push(nums, 20);
        sort(nums);              // in place: [10, 20, 30]
        println(sum(nums));      // 60
        x: int = pop(nums);
        println(x);              // 30
    }
    ```
  </TabItem>
</Tabs>

## dict

Dictionary (hash map) operations. Dicts map keys to values and support O(1) average-case lookup, insertion, and deletion. The `std/dict.qa` wrappers add higher-level helpers on top of the primitives below.

### Primitives

| Function | Signature | Description |
|----------|-----------|-------------|
| `dict.has` | `(dict(K,V), K) -> bool` | True if key is present |
| `dict.len` | `(dict(K,V)) -> int` | Number of key-value pairs |
| `dict.delete` | `(dict(K,V), K) -> void` | Remove a key (no-op if absent) |
| `dict.keys` | `(dict(K,V)) -> [K]` | All keys as an array |
| `dict.values` | `(dict(K,V)) -> [V]` | All values as an array |

### std/dict helpers

Import `std/dict.qa` for higher-level utilities that all operate on `dict(str, int)`.

| Function | Description |
|----------|-------------|
| `get_or(d, key, default)` | Safe lookup -- returns `default` when key is absent |
| `increment(d, key, amount)` | Add `amount` to an existing key, or set it if missing |
| `set_if_absent(d, key, value)` | Insert only when the key does not yet exist |
| `merge(a, b)` | New dict combining both; `b` wins on duplicate keys |
| `from_keys(keys, value)` | Build a dict mapping every key in an array to the same value |
| `count(arr)` | Frequency map -- count occurrences of each string in an array |
| `filter_gte(d, n)` | New dict keeping only entries whose value is `>= n` |
| `sum_values(d)` | Sum of all values |

<Tabs>
  <TabItem label="Module prefix">
    ```quant
    import dict

    fn main() -> void {
        scores: dict(str, int) = {"alice": 90, "bob": 75};
        println(dict.has(scores, "alice"));    // True
        println(dict.len(scores));             // 2

        dict.delete(scores, "bob");
        println(dict.len(scores));             // 1

        keys: [str] = dict.keys(scores);
        println(keys[0]);                      // alice
    }
    ```
  </TabItem>
  <TabItem label="Named import">
    ```quant
    from dict import get_or, increment, count

    fn main() -> void {
        words: [str] = ["go", "quant", "go", "go"];
        freq: dict(str, int) = count(words);
        println(get_or(freq, "go", 0));        // 3
        println(get_or(freq, "rust", 0));      // 0

        increment(freq, "quant", 5);
        println(freq["quant"]);                // 6
    }
    ```
  </TabItem>
</Tabs>

## json

JSON encoding and decoding. `json.encode` handles any Quant value; the decode functions extract typed fields from a JSON object string. The `std/json.qa` module re-exports these with the same names.

### Primitives

| Function | Signature | Description |
|----------|-----------|-------------|
| `json.encode` | `(value) -> str` | Encode any value to a JSON string |
| `json.decode_str` | `(str, key: str) -> str` | Extract a string field |
| `json.decode_int` | `(str, key: str) -> int` | Extract an integer field |
| `json.decode_float` | `(str, key: str) -> float` | Extract a float field |
| `json.decode_bool` | `(str, key: str) -> bool` | Extract a boolean field |
| `json.has` | `(str, key: str) -> bool` | True if the key is present |
| `json.is_null` | `(str, key: str) -> bool` | True if the field is `null` |
| `json.keys` | `(str) -> [str]` | All keys of the JSON object |
| `json.parse` | `(str) -> dict(str, str)` | Parse an object; all values coerced to strings |

### std/json helpers

| Function | Description |
|----------|-------------|
| `get_or(s, key, default)` | Safe field read with a fallback string |
| `from_str_dict(d)` | Encode a `dict(str, str)` to JSON |
| `from_int_dict(d)` | Encode a `dict(str, int)` to JSON |

<Tabs>
  <TabItem label="Encoding">
    ```quant
    fn main() -> void {
        d: dict(str, int) = {"port": 8080, "workers": 4};
        println(json.encode(d));          // {"port":8080,"workers":4}
        println(json.encode("hello"));    // "hello"
        println(json.encode(True));       // true
        println(json.encode(42));         // 42
    }
    ```
  </TabItem>
  <TabItem label="Decoding">
    ```quant
    fn main() -> void {
        s: str = "{\"name\":\"alice\",\"age\":30,\"active\":true}";
        println(json.decode_str(s, "name"));    // alice
        println(json.decode_int(s, "age"));     // 30
        println(json.decode_bool(s, "active")); // True
        println(json.has(s, "missing"));        // False
    }
    ```
  </TabItem>
  <TabItem label="Named import">
    ```quant
    from json import encode, decode_str, decode_int, get_or

    fn main() -> void {
        body: dict(str, str) = {"token": "abc123"};
        req: str = encode(body);
        resp: str = "{\"status\":\"ok\",\"user\":\"alice\"}";
        println(get_or(resp, "user", "unknown"));  // alice
        println(get_or(resp, "role", "guest"));    // guest
    }
    ```
  </TabItem>
</Tabs>

## socket

Raw TCP networking. Sockets are identified by an integer handle. All operations return `-1` / `""` / `False` on failure. See the [Socket guide](/system/sockets/) for full examples.

| Function | Signature | Description |
|----------|-----------|-------------|
| `socket.connect` | `(host: str, port: int) -> int` | Open a TCP connection; returns socket id or `-1` |
| `socket.listen` | `(port: int, backlog: int) -> int` | Bind and listen on port; returns socket id or `-1` |
| `socket.accept` | `(server: int) -> int` | Accept one connection; blocks until a client arrives |
| `socket.send` | `(sock: int, data: str) -> int` | Send data; returns bytes sent or `-1` |
| `socket.recv` | `(sock: int, n: int) -> str` | Receive up to `n` bytes; `""` on close or error |
| `socket.close` | `(sock: int) -> bool` | Close the socket |
| `socket.peer_addr` | `(sock: int) -> str` | Remote `"host:port"`, or `""` on error |

### std/socket helpers

| Function | Description |
|----------|-------------|
| `connect(host, port)` | Alias for `socket.connect` |
| `listen(port, backlog)` | Alias for `socket.listen` |
| `accept(server)` | Alias for `socket.accept` |
| `send(sock, data)` | Alias for `socket.send` |
| `recv(sock, n)` | Alias for `socket.recv` |
| `close(sock)` | Alias for `socket.close` |
| `peer_addr(sock)` | Alias for `socket.peer_addr` |
| `http_get(host, port, path, buf_size)` | Full HTTP/1.0 GET: connect, send request, recv response, close |

<Tabs>
  <TabItem label="TCP client">
    ```quant
    fn main() -> void {
        sock: int = socket.connect("example.com", 80);
        if (sock < 0) { println("failed"); return; };
        socket.send(sock, "GET / HTTP/1.0\r\nHost: example.com\r\n\r\n");
        println(socket.recv(sock, 4096));
        socket.close(sock);
    }
    ```
  </TabItem>
  <TabItem label="TCP server">
    ```quant
    fn main() -> void {
        srv: int = socket.listen(8080, 5);
        client: int = socket.accept(srv);
        if (client >= 0) {
            data: str = socket.recv(client, 1024);
            socket.send(client, data);   // echo
            socket.close(client);
        };
        socket.close(srv);
    }
    ```
  </TabItem>
  <TabItem label="http_get helper">
    ```quant
    from socket import http_get

    fn main() -> void {
        resp: str = http_get("httpbin.org", 80, "/ip", 4096);
        println(resp);
    }
    ```
  </TabItem>
</Tabs>

## Top-level print / println

`print` and `println` are available without any module prefix and are the most common output functions.

```quant
fn main() -> void {
    name: str = "Quant";
    version: int = 1;
    println(`Hello from {name} v{version}!`);
}
```

For output that mixes multiple values or needs formatting, use backtick string interpolation rather than format specifiers.

## buf

Mutable string buffers -accumulate chunks cheaply, then write everything to any file descriptor in one POSIX `write(2)` call.

All `buf.*` functions are always available as dotted calls -no import statement required. A buffer is typed as `[str]` and mutates in place.

| Function | Signature | Description |
|----------|-----------|-------------|
| `buf.new` | `() -> [str]` | Allocate a new empty buffer |
| `buf.write` | `([str], str) -> void` | Append a string chunk |
| `buf.writeln` | `([str], str) -> void` | Append a string chunk + newline |
| `buf.to_str` | `([str]) -> str` | Join all chunks into one string (non-destructive) |
| `buf.len` | `([str]) -> int` | Total character count across all chunks |
| `buf.clear` | `([str]) -> void` | Remove all chunks, leaving the buffer empty |
| `buf.flush` | `([str], int) -> int` | Join chunks, write to fd, clear buffer; returns bytes written |

<Tabs>
  <TabItem label="Write to stderr">
    ```quant
    fn eprint(msg: str) -> void {
        b: [str] = buf.new();
        buf.writeln(b, msg);
        buf.flush(b, sys.stderr_fd());
    }

    fn main() -> void {
        eprint("error: something failed");
        eprint("hint: check your arguments");
    }
    ```
  </TabItem>
  <TabItem label="Custom printf">
    ```quant
    from string import replace_first, from_int, from_float

    fn printf(fd: int, fmt: str, args: ...str) -> int {
        b: [str] = buf.new();
        result: str = fmt;
        i: int = 0;
        while (i < len(args)) {
            result = replace_first(result, "{}", args[i]);
            i = i + 1;
        };
        buf.write(b, result);
        return buf.flush(b, fd);
    }

    fn main() -> void {
        printf(sys.stdout_fd(), "x = {}, pi = {}\n",
               from_int(42), from_float(3.14));
        printf(sys.stderr_fd(), "warn: {} retries\n", from_int(3));
    }
    ```
  </TabItem>
  <TabItem label="Build a string">
    ```quant
    from string import from_int

    fn repeat_str(s: str, n: int) -> str {
        b: [str] = buf.new();
        i: int = 0;
        while (i < n) {
            buf.write(b, s);
            i = i + 1;
        };
        return buf.to_str(b);
    }

    fn main() -> void {
        println(repeat_str("ha", 3));   // hahaha
    }
    ```
  </TabItem>
</Tabs>

## file

File system operations. All functions take a file path as their first argument.

| Function | Signature | Description |
|----------|-----------|-------------|

| `file.write` | `(str, str) -> bool` | Write/overwrite file; creates if absent; returns success |
